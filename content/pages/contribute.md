Have I missed your set? Want to add some stuff? Need something in your artist
profile? Want to correct a genre?

## Submitting a set

1. Find the set on Mixcloud or SoundCloud.
2. Note the event, edition/date, artist, and genre(s).
3. [Open an issue](https://github.com/hibby/furrymixes/issues/new) or send a telegram message with the link and details.

## What I need from you

- A working Mixcloud or SoundCloud link
- The event and date (or best guess if unsure)
- Artist name, spelled how they'd want it credited
- Genre(s), if you know them

## If you're comfortable with GitHub

Pull requests welcome — see the [repo](https://github.com/hibby/furrymixes) for the content structure.
